# ELSA CAD 工程記憶與文件能力契約

## 目的

讓艾西能將**使用者明確選取**的 DWG 或 DXF 圖紙轉為可追溯、可檢索的工程記憶與文件任務。這項能力以 N1 的受控解析工作者為唯一執行位置；Android App 只負責提交、查看回報與取得已驗證產物，絕不直接改寫原始圖紙。

## 輸入邊界

| 類別 | 接受條件 | 不接受情況 |
|---|---|---|
| DXF | 使用者從系統選檔器選取；N1 回報檔案雜湊與 MIME／副檔名檢查 | 未經使用者選取的手機檔案、Root／Vault 或 App 私有資料 |
| DWG | 使用者選取後，由 N1 先回報解析器相容性與轉換狀態 | App 以猜測方式宣稱已可讀取，或將未知版本當作已解析 |
| 圖紙修改 | 僅可指定產生副本、註解層、差異提案或簡單 DXF 修正版 | 直接覆寫原始圖、未經核准的批次變更 |

## N1 解析報告

每份報告須有 `report_id`、`source_task_id`、`captured_at`、`source_file_sha256`、解析器名稱與版本。可公開至 App 的摘要欄位如下：

| 欄位 | 目的 | 顯示規則 |
|---|---|---|
| 格式與相容性 | DWG／DXF、版本、解析是否成功 | 不相容時顯示失敗原因，不猜測內容 |
| 圖層摘要 | 圖層名稱、數量、可見性及主要類別 | 顯示中繼資料，不取代圖面審閱 |
| 文字與尺寸摘要 | 可擷取文字數、尺寸實體數、可能的單位／比例線索 | 未能確認比例或單位時標示「未確認」 |
| 圖塊與圖框 | 圖塊名稱／數量、可辨識圖框及版次線索 | 不將圖塊名稱自動解讀為工程事實 |
| 安全與完成度 | 檔案大小、雜湊、解析時間、警告與截斷狀態 | 截斷時禁止宣稱完整分析 |

## 艾西可做的分析

艾西可利用已驗證的解析報告，建立圖紙摘要、圖層／標註問答、跨版本變更清單、工程檢核表初稿、材料或設備清單初稿，並產製 Markdown、DOCX 或 PDF。所有含有數字、尺寸、工程規格或安全結論的段落，必須附上圖紙來源欄位或明示為「待人工確認」。

> AI 的摘要、比較和建議是輔助工作產物；它不取代圖說、專業簽證、法規審查、結構判定或施工核可。

## 文件與修改產物

每個文件或圖紙副本必須回報格式、大小、SHA-256、建立時間、來源任務、驗證狀態、N1 索引狀態與 R2 封存狀態。產物須以原始圖的雜湊、任務 ID 和版本建立可追溯關聯。若輸出包含改圖，另須有差異摘要、回滾位置與主人核准狀態。

## App 降級規則

未收到 N1 完整報告時，App 必須顯示「待解析」或「未回報」。聊天文字、檔名、縮圖或 CAD Reader 成功開啟的畫面都不能被視為 N1 已完成解析或艾西已具備工程知識的證據。
