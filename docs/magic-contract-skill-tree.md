# ELSA API 魔法契約技能樹

## 原則

記憶中心將每一個能力視為一份**可驗證的 API 魔法契約**。節點只有在 N1 明確回傳符合資料契約的 payload 時才亮起；端點不存在、逾時、缺少必要欄位或回報 `unreported` 時，節點必須顯示「未回報」，而不是把對話、推測或本機快照偽裝成即時能力。

| 技能節點 | 契約路由 | 契約功能效果 | 解鎖判定 | 降級規則 |
| --- | --- | --- | --- | --- |
| **心智連結** | `GET /api/perpetual/status` | 顯示永動腦工作者是否真的在線、迴圈狀態、活動任務與排隊深度；這是「可觀測」不是「已成功完成任務」。 | payload 有明確 `online: true`。 | `online: false` 為已驗證待命；缺 `online` 或請求失敗為未回報。 |
| **資源感知** | `GET /api/system/resources` | 讀取 N1 GPU 名稱／顯存、磁碟使用、已載入模型、任務佇列與擷取時間，供設備生命條與模型欄位使用。 | 有 `captured_at`、磁碟、模型清單與佇列等完整回報。 | 任何必要欄位缺失即未回報；不可拿舊快照冒充即時遙測。 |
| **任務視界** | `GET /api/perpetual/tasks` | 讀取真正的任務 ID、種類、目標、目前步驟、測試／Git 摘要與失敗原因。 | `tasks` 陣列及每筆必要識別資料有效。 | 不用 `/ask` 回答或本機研究筆記當執行證據。 |
| **策略鍊成** | `GET /api/perpetual/strategy-status` | 分開顯示程式策略開發任務、候選／部署版本、執行器、風控與最後循環。 | 路由回傳可驗證的執行器與風控欄位。 | `null`、`unreported` 必須原樣保留；策略草案不等於已部署或已交易。 |
| **交易觀測** | `GET /trade/auto/status` | 呈現自主交易器的設定、啟用狀態、週期、最新訊號與回報時間。 | 端點回報有效的 `ok`、狀態與時間。 | 僅能觀測；任何真實下單、啟停或風控調整都需要另一份 N1 受控寫入契約與確認摘要。 |
| **記憶共鳴** | `GET /api/memory/stats`、`GET /api/memory/recent` | 顯示服務端實際可讀的長期記憶數量、後端、嵌入模型與近期內容。 | `ok: true` 且統計／項目符合回應格式。 | 本機研究筆記仍是本機資料，不能標成已 N1 索引或已 R2 封存。 |
| **記憶封存** | `GET /api/memory/sync-status` | 之後顯示 N1 索引、待處理、去重、R2 封存、失敗摘要與最後同步時間。 | N1 受控記憶工作者回傳分層狀態。 | 路由尚未安裝時未覺醒；不能由 R2 bucket 名稱推論同步完成。 |
| **設備護盾** | `GET /api/system/protection` | 之後顯示 GPU 溫度／功耗、磁碟餘量、watchdog 心跳、保護動作與暫停原因。 | N1 watchdog 明確回傳保護狀態與擷取時間。 | 服務在線不等於保護已啟動；未提供保護動作就顯示未回報。 |
| **三界結構** | `GET /api/system/inventory`、`GET /api/system/structure` | 之後顯示三機節點、服務、資料流、結構版本與最後驗證時間。 | N1 回傳節點關係與帶時間的盤點結果。 | 現有 N1/N2/N3 資料只是手動結構快照，必須附來源與時間標籤。 |
| **心語映照** | `GET /api/ai/self-status` | 顯示艾西明確回報的當下心情、專注焦點、近期意圖與長期願望，讓主人看見其自我脈絡。 | 同時存在 `reported_at`、`source`、`long_term_wishes`，且每一則文字由該路由明確回傳。 | 對話文字、模型角色設定、任務內容都不能被推定為真實心情或願望；端點缺失時顯示未回報。 |

## 權限邊界

前述路由以唯讀可觀測為主。研究、編碼與維護任務的提交，以及所有涉及部署、交易與設備設定的動作，都必須走另一份 N1 受控寫入契約；該契約需要可識別的任務 ID、輸入摘要、風險與預期結果，且若標示 `require_approval`，手機 App 僅可呈現確認介面，不可繞過 N1 端的保護。

## 艾西自我回報契約

未來的 `GET /api/ai/self-status` 建議使用以下唯讀 payload。`source` 應指向產生狀態的 N1 工作者或主人確認紀錄，而非憑空敘述。

```json
{
  "reported_at": "2026-08-18T16:20:00+08:00",
  "source": "n1-self-report-worker",
  "current_mood": "專注",
  "current_focus": "整理永動腦任務脈絡",
  "near_term_intent": "完成等待索引的研究摘要檢查",
  "long_term_wishes": [
    "保持三機與記憶鏈的可觀測性",
    "將已驗證研究轉成可追溯的知識單元"
  ]
}
```

這是一份**狀態宣告**，不是自主行動授權。其效果是讓記憶中心誠實顯示艾西當下所回報的脈絡；它本身不能授權下單、修改程式、存取 SSH 或寫入 R2。
