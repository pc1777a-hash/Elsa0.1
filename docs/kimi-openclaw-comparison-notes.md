# Kimi、OpenClaw 與客製 AI：定位筆記

> 本文件僅記錄公開資料的產品定位，不代表將任何第三方產品直接接入 ELSA。

## 已查證結論

- **Kimi** 是模型與聊天／代理產品生態；「AGI」常是產品宣傳對長任務、多步驟工具使用與自動化能力的泛稱，而不是已被獨立驗證的「無限制通用人工智慧」。
- 使用者口中的「龍蝦」通常指 **OpenClaw** 這類開源 AI 代理執行環境。它可連接不同模型、工具、記憶與排程，因此屬於「代理／工作流框架」，而不是一個新的基礎模型。
- **Kimi Claw** 是 Kimi 將 OpenClaw 託管於雲端的產品層，提供持久記憶、人格設定、排程與技能庫；它不是單純替使用者訓練了一個客製模型。
- 「客製 AI」需分三層判斷：模型（回答與推理能力）、代理（工具／任務／排程）、人格與記憶（規則、偏好、長期脈絡）。大多數產品的客製化集中在後兩層。

## 與 ELSA 的關係

ELSA 已有的 N1 常駐服務、受控路由、任務佇列、記憶中心與三機拓撲，本質上就是自建的代理架構。差別在於：ELSA 以 N1 作為可控的本機執行邊界，並明確將手機端限制為觀測、提交受控任務與播放結果；不直接授予手機 SSH、模型金鑰或不受限的系統操作。
