# ELSA 控制中心設計規格

## 導航架構

底部分頁調整為「控制台、對話、記憶、日誌、設定」。控制台採黑底、角色主視覺與圓角控制元件；對話維持使用者提供的舊版風格，作為艾西主要互動入口。

## 控制台

控制台頂部使用左側功能選單、中央 ELSA 標籤與右側資料入口。中央顯示艾西肖像，下面放置「我是艾西，你的 AI 戰略副官」的狀態文案。肖像下方設置三個資料框：服務健康、策略／交易模式、待確認操作。資料框只顯示經 API 驗證的值；缺少自動化狀態端點時，顯示「尚未連接受控操作服務」，而不以假狀態替代。

## 記憶中心

記憶中心分成「本機對話摘要」與「服務端長期記憶」兩區。本機摘要會從已保存的對話紀錄計算訊息數、最後更新時間和最近一則使用者訊息；服務端長期記憶只有在 API 可用時才顯示內容。若尚未提供記憶 API，畫面顯示清楚的連線需求與不含敏感資訊的設計原則。

## 即時日誌

日誌頁採時間序列卡片。每次控制台重新整理或讀取到服務資料時，將實際成功／失敗事件寫入本機事件序列；不會將推測、角色回答或未驗證背景狀態當成日誌。未來若服務端提供事件串流，可在同一頁加上 WebSocket 或輪詢來源。

## 自主操作狀態框

操作框只顯示目前已知交易模式、原生服務健康、交易所配置與待確認操作。它不會呼叫啟動、停止、單輪交易或下單路由。當服務端日後提供受控操作契約時，此框會先展示操作摘要與風險欄位，再讓使用者明確確認。
